# CzechDictionary

## About app
- Add new words in your dictionary
- Choose favourite words
- Save words on device
- Get translation, sense and other information for new word

## Stack
- Kotlin
- Compose
- Retrofit + OkHttp
- Koin
- Room
- MVVM
- Clean Architecture
